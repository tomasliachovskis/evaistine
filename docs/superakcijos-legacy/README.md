# superakcijos.lt legacy research

eVaistine.lt is a fork of the superakcijos.lt grocery price aggregator. The
files in this folder are that project's SEO, Search Console and keyword
research, kept in their original wording for reference.

- The data, URLs and numbers here are about superakcijos.lt (groceries,
  Maxima/Lidl/Rimi/Iki/Norfa), not eVaistine.lt. Don't quote them as this
  site's results.
- The methods still apply: how meta titles were tested, how keyword pages
  were cleaned with `exclude_terms`, how GSC CTR fixes were picked.
- `ahrefs-export-*.csv` and `kw-akcija.csv` are grocery keyword exports. The
  pharmacy keyword list is built separately (see `TODO.md`).
